# Lancemates — Frontend Take-Home

A small take-home assignment for frontend developer candidates at Lancemates.

**Your task lives in [`TASK.md`](./TASK.md).** Read it first.

## Quick start

```bash
npm install
npm run web
```

Minimal [Expo](https://expo.dev) app (React Native + TypeScript). No backend required.

## Submitting

Follow the instructions in `TASK.md` (open a PR, or share a link to a repo/zip with your notes).
